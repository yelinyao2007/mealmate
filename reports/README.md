# Reports

This directory holds reusable templates and completed test reports for MealMate.

## Suggested layout

- `templates/`: reusable report skeletons
- `nightly/`: completed nightly regression reports
- `checklists/`: execution runbooks and operator checklists

## Naming

- Nightly report: `YYYY-MM-DD-nightly-test-report.md`
- Incident follow-up: `YYYY-MM-DD-incident-summary.md`

## Recommended flow

1. Copy the appropriate file from `reports/templates/`
2. Save it into `reports/nightly/` or another target folder
3. Fill in results as the run progresses
4. Keep failed evidence and skipped reasons explicit
